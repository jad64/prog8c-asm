Turbo Macro Pro v1.2 Compatible Assembly Language Compiler for Commodore 64
===========================================================================

*Author's Note*

This project is something of an experiment. I was curious about how larger projects are created in prog8c and what capabilities the language offers.
Personally, I enjoy programming in prog8c.
As for the size of the resulting code? That involves certain trade-offs.
I am working on the same project in assembly language (64tass) in parallel—though I’m not sure if I’ll finish it (even though, really, I should). I am curious to compare the code size and execution speed.
